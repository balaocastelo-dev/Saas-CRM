Resumo Operacional

Este painel permite gerenciar campanhas ativas para o Balão da Informática Castelo usando os ramais da Telefonia Fácil. Seus contatos do WhatsApp são redirecionados automaticamente para o número padrão da loja para agilizar o pós-atendimento.

Importante sobre limites e boas práticas:

O sistema está limitado a uma taxa segura de chamadas por minuto (padrão 1 por minuto) para evitar bloqueios SIP e garantir ligações somente para clientes com relacionamento prévio (assistência, pedidos, orçamentos, etc.).
